# Superstore Sales & Profit Analysis

## Project Overview

This is an end-to-end Data Analysis project developed using **Microsoft Excel, SQL, and Power BI**.

The project focuses on analyzing Superstore sales data to identify key business insights related to sales, profit, products, customers, categories, regions, and monthly performance.

---

## Tools Used

- Microsoft Excel
- SQL
- Power BI
- DAX

## Excel Data Cleaning

Microsoft Excel was used for initial data preparation and cleaning.

The following steps were performed:

- Removed unnecessary columns
- Standardized column names
- Checked for missing values
- Checked for duplicate records
- Cleaned text values
- Verified date columns
- Prepared the dataset for SQL and Power BI analysis

---

## SQL Analysis

SQL was used to perform business analysis and extract meaningful insights.

The analysis includes:

- Total Sales
- Total Profit
- Total Orders
- Total Quantity
- Sales by Category
- Profit by Category
- Sales by Region
- Profit by Region
- Monthly Sales
- Year-wise Performance
- Top 10 Products by Sales
- Bottom 10 Products by Sales
- Loss-Making Products
- Top Customers
- Discount vs Profit Analysis
- Top Products within Each Category
- Customers with Sales Above Average
- Monthly Sales Growth
- Profit Margin by Category
- Best Performing Product in Each Region

SQL concepts used:

- Aggregate Functions
- GROUP BY
- HAVING
- Subqueries
- Common Table Expressions (CTE)
- Window Functions
- ROW_NUMBER()
- LAG()
